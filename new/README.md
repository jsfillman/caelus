# New Experimental Synth Prototypes

This directory contains experimental prototypes and early-stage development code for new synthesizer concepts. These are generally simpler implementations used to test ideas before incorporating them into the main synth projects.

## Contents

- **mini.py**: Prototype implementation of a minimalist synthesizer with basic functionality
- **mini-simple.py**: Simplified version of the mini prototype for testing core concepts

## Purpose

This area serves as a sandbox for:
- Testing new synthesis algorithms
- Developing simplified proof-of-concepts
- Experimenting with alternative approaches to audio generation
- Prototyping features before integrating them into larger projects

These prototypes are not meant for production use and may be unstable or incomplete.
